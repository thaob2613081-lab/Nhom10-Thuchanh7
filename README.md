# Bài thực hành buổi 7: Dịch vụ tiện ích và sử dụng sáng tạo

## Nội dung thực hành
- Bài 1: Hợp tác trực tuyến bằng Google Docs.
- Bài 2: Tạo biểu mẫu bằng Google Forms.
- Bài 3: Thiết kế website cá nhân bằng Google Sites.
- Bài 4: Quản lý công việc bằng Google Keep/Notion.
- Bài 5: Quản lý dự án tổ chức sự kiện chào mừng sinh viên khóa 51 bằng Trello.

## Mục tiêu
Rèn luyện kỹ năng sử dụng tiện ích trực tuyến, cộng tác nhóm và quản lý công việc, dự án.

## Công cụ sử dụng
- Google Docs
- Google Forms
- Google Sites
- Google Keep/Notion
- Trello
